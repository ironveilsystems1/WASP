# Runtime allowlist — destinations WordPress and WASP genuinely need.
#
# A leading dot matches subdomains: .wordpress.org covers api.wordpress.org
# and downloads.wordpress.org. Without the dot the match is exact.
#
# ADD NOTHING HERE WITHOUT KNOWING WHY. Every entry is a route out for a
# compromised site, and the reason this control is worth having is that the
# list is short. "A plugin seemed to want it" is how an allowlist becomes a
# formality.
#
# Use discovery to find what a specific site actually needs:
#   wasp-egress discovery report

# ── WordPress core, plugin and theme updates ─────────────────────────────────
.wordpress.org
.w.org

# ── WASP's own operations ────────────────────────────────────────────────────
# Vulnerability feed
www.wordfence.com
# CrowdSec central API and threat intelligence
.crowdsec.net
# GeoIP database refresh
.maxmind.com
# Alpine package updates
.alpinelinux.org

# ── Container registries: not here, deliberately ─────────────────────────────
# .docker.io, ghcr.io and .githubusercontent.com used to be listed "for
# update.sh". update.sh never came through this proxy: it runs on the host, and
# the host's own output chain reaches 80/443 directly. This file is read for
# wp-front, so the only thing those entries did was let a compromised WordPress
# fetch tools from GitHub and PUT to a registry. If one site's plugin updater
# really needs GitHub:  doas wasp-egress.sh allow raw.githubusercontent.com
#
# dstdomain is a splay tree and treats a subdomain of an already-listed parent
# as a FATAL config error. Never list both a leading-dot parent and any of its
# subdomains in the same file.

# ── NOT included, deliberately ───────────────────────────────────────────────
# Gravatar, Google Fonts, jsdelivr, unpkg, and the rest of the CDN estate that
# WordPress themes reach for. They are usually optional, they are a common
# exfiltration path, and a site that visibly breaks without one is a site
# whose dependency you have just discovered. Add them if a client's site
# genuinely needs them, after discovery has shown it does.

# ── Commercial themes and page builders ──────────────────────────────────────
# DELIBERATELY EMPTY. Builder licence domains are chosen at install time and
# appended below, so a site that does not run Elementor never carries
# elementor.com as a reachable destination.
#
# An earlier version shipped nine of them baked in, which was backwards: this
# file is the list of places a COMPROMISED WordPress may still reach, so every
# unused entry is pure surface for no benefit.
#
# Add one later:   doas wasp-egress.sh allow .elementor.com
# See what a site actually needs:  doas wasp-egress.sh discovery
